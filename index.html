Industry-standard definitions

Metaphor · Pond

Recurrent / state-space hidden state

A fixed-size vector (or set of vectors) that is updated at every time step and carries a compressed summary of the past. In RNNs and LSTMs this is the hidden (and cell) state. In modern state-space models (SSMs) such as S4 and Mamba, it is a structured dynamical state—often continuous-time underneath, discretized once per token. Memory cost stays roughly constant as the sequence grows; exact old details can fade or mix.

Also called: latent state, SSM state, recurrent state, evolving context

Metaphor · Notebook

Attention memory (key–value cache)

A mechanism that stores a record for each past position and retrieves relevant entries by comparing a query to keys, then blending values. In Transformers this is self-attention or cross-attention; at inference the stored keys and values are the KV cache. Memory and compute typically grow with sequence length, but exact lookup of earlier tokens is reliable.

Also called: attention, self-attention, cross-attention, KV cache, retrieval over context

Metaphor · Multi-head

Multi-head attention

Running several attention operations in parallel on the same input, each with its own projections (query, key, value). Outputs are concatenated (and usually projected). Different heads can specialize on different relations or positions. Standard since Vaswani et al., “Attention Is All You Need” (2017).

Also called: MHA, multi-head self-attention (MHSA)
