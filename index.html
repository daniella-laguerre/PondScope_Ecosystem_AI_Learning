Definitions — beside the path

Metaphor · Pond · lesson 01

Recurrent / state-space hidden state

A fixed-size evolving summary of the past (RNN/LSTM hidden state; SSM state in S4/Mamba). Cost stays flat; exact old details can fade.

Also: latent state, SSM state, recurrent state

Metaphor · Notebook · lesson 02

Attention memory (KV cache)

A record per past position; query matches keys and blends values. Exact lookup; memory grows with length.

Also: self/cross-attention, KV cache

Metaphor · Multi-head · lesson 03

Multi-head attention

Several attention heads in parallel, each with its own Q/K/V. Heads can specialize on different places or relations.

Also: MHA, MHSA
